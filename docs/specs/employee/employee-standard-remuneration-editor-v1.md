# 従業員別標準報酬月額管理 V1

## 目的

健康保険・厚生年金の控除計算で使用する標準報酬月額を、従業員・適用期間ごとに管理する。
確定前の誤入力が給与計算へ混入しないよう、下書き・検証・確定を分離する。

## 操作経路

控除マスターの「健康・介護保険」または「厚生年金」詳細から
「従業員別標準報酬月額を編集」を開く。

## 管理項目

- 従業員
- 適用開始日・適用終了日
- 健康保険用標準報酬月額
- 厚生年金用標準報酬月額
- 決定区分（算定理由：資格取得・定時決定・随時改定・手入力）
- 備考
- 変更理由

## 更新フロー

1. 画面入力またはCSV取込
2. 下書き保存・検証
3. 検証済みデータの確定
4. 確定後、既存の `employee_standard_remuneration` を給与・法定控除計算が参照

下書き中は確定テーブルを更新しない。適用期間の重複、存在しない従業員、
標準報酬月額マスターに存在しない金額は検証エラーとする。

締め済み期間に重なる変更は警告し、再締めが必要であることを確認しない限り確定しない。

## CSV形式

`employeeCode,healthStandardRemuneration,pensionStandardRemuneration,effectiveFrom,effectiveTo,sourceType,note`

画面のCSV出力を基準フォーマットとする。取込後も即時確定せず、必ず画面上で検証・確定する。

## 週所定労働時間

既存API・DBの `standardWorkingHours` / `standard_working_hours` は互換性維持のため変更しない。
画面・CSV上の表示名は「週所定労働時間」とし、0～168時間/週の範囲で入力する。
この値は週給の時間単価、月給の時間換算、時給者の月額見込などに使用される。

## 決定区分の互換表示

新規登録では「資格取得・定時決定・随時改定・手入力」を使用する。
過去データの `LOCAL_FIXTURE`、`LEGACY`、`CSV`、`IMPORT` はDB値を変更せず、
画面上ではそれぞれ「初期登録・移行データ・CSV取込・外部取込」と表示する。
これ以外の既存コードも英字を直接表示せず「既存データ」として表示し、保存時に元のコードを維持する。

## 社会保険計算との連携

| 項目 | 計算基礎 | 標準報酬月額の参照 |
| --- | --- | --- |
| 健康保険 | 健康保険用標準報酬月額 × 健康保険料率 | する |
| 介護保険 | 健康保険用標準報酬月額 × 介護保険料率 | する |
| 子ども・子育て支援金 | 健康保険用標準報酬月額 × 子ども・子育て支援金率 | する |
| 厚生年金 | 厚生年金用標準報酬月額 × 厚生年金保険料率 | する |
| 雇用保険 | 総支給額（見込計算では月額見込額）× 雇用保険料率 | しない |

月次給与計算は `vw_monthly_pay_slip_tax_calculation`、日次の法定準備金初期値は
`DailyStatutoryDeductionEstimateService` を経由して上記と同じ計算基礎を使う。
各計算は1円単位で四捨五入する。適用期間に対応する標準報酬月額が未登録・重複している場合は、
月次計算を準備未完了として扱い、誤った値で確定しない。

### 回帰確認（2026年11月14日）

- 健康・介護保険が健康保険用標準報酬月額を参照すること
- 子ども・子育て支援金が健康保険用標準報酬月額を参照すること
- 厚生年金が厚生年金用標準報酬月額を参照すること
- 雇用保険が標準報酬月額ではなく総支給額を参照すること
- 月次結合テストで健康保険 `16,845円`、子ども・子育て支援金 `345円`、
  厚生年金 `27,450円`、雇用保険 `1,800円` の期待値を検証すること

ローカルの2026年度料率は、静岡支部の健康保険（被保険者負担4.805%）、
介護保険（被保険者負担0.81%）、子ども・子育て支援金（被保険者負担0.115%）、
厚生年金（被保険者負担9.15%）、建設事業の雇用保険（労働者負担0.6%）を使用している。
料率はコードへ固定せず `insurance_rate_master` の適用年度から取得する。
