# V1残課題一覧

V1安定化で判明した未確定事項・後続対応を一元管理する。
新しい課題はこのファイルへ追記し、完了時は削除せず「完了」へ更新して判断経緯を残す。

## 記載ルール

| 項目 | 内容 |
|---|---|
| ID | `V1-ドメイン-連番` |
| 状態 | 未着手 / 検討中 / 対応中 / 完了 / V2へ移送 |
| 優先度 | 高 / 中 / 低 |
| 決定事項 | 現時点で確定している仕様 |
| 残る判断 | 実装前に決める必要があること |
