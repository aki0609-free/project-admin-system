# 従業員別の日報初期額・手当控除設定

## 目的

勤務態度手当・管理手当と法定準備金の日報初期額を、従業員コードをRuleへ直書きせず、
従業員管理の「手当・控除設定」で管理する。

## 管理場所

`従業員管理 > 従業員編集 > 手当・控除設定`

対象項目ごとに次を管理する。

- 適用有無
- 適用開始日
- 日報初期額

設定変更時は有効期間付きの履歴として保存する。日報は勤務日時点で有効な設定を参照する。

## 計算仕様

### 勤務態度手当

1. 勤務日時点の従業員別 `employeeDailyAmount` をRuleへ渡す。
2. Rule `EMPLOYEE_CONFIGURED_DAILY_AMOUNT` がその金額を初期値として返す。
3. 日報入力者は実績に応じて手入力で変更できる。

### 管理手当

勤務態度手当と同じ `EMPLOYEE_CONFIGURED_DAILY_AMOUNT` Ruleを使用する。
管理手当がある従業員だけを有効にし、勤務日時点の従業員別日報初期額を表示する。
日報入力者は実績に応じて手入力で変更できる。

### 寮費

- 寮タイプは任意の補助情報とする。
- 寮費日額は従業員ごとに直接設定する。
- 同じ寮タイプでも異なる日額を設定できる。
- 残額は寮費日額と有効期間、日報の徴収実績から残高基盤が計算する。

### 法定準備金

1. 勤務日時点の従業員別 `employeeDailyAmount` をRuleへ渡す。
2. 1円以上が設定されている場合、その金額を初期値とする。
3. 0円の場合は既存仕様どおり、次の予測法定控除合計を20日で按分する。

```text
所得税 + 住民税 + 健康・介護保険 + 子ども・子育て支援金
  + 厚生年金 + 雇用保険
```

4. 日報入力者は実際の預り額へ手入力で変更できる。

## 初期移行

- 添付された「富陽 新給料ソフト資料」の基本給は移行対象外。
- 勤務態度手当と法定控除預り分は、2026年10月31日を適用開始日として登録する。
- 管理手当、寮費、携帯電話貸出料、Wi-Fi使用料も、資料に明示値がある従業員だけ2026年10月31日から有効にする。
- `-` または空欄は勤務態度手当を無効とする。
- その他の空欄も0円へ変換せず、その項目を未設定のままにする。
- 法定準備金は既存表示を維持するため全従業員へ0円設定を作り、個別金額のある従業員だけ10月31日から新しい履歴を追加する。
- 携帯電話貸出料は残高に変換せず、項目の利用有無だけを設定する。実額は明細登録を正とする。
- Wi-Fi使用料は残高管理せず、日報手入力項目として扱う。
- 基本給は従業員契約情報を正とし、この資料から更新しない。

## 検証観点

- 2026年10月30日の日報では新しい個別額を使わない。
- 2026年10月31日以降の日報では個別額が初期表示される。
- 日報上で手入力した金額は初期額より優先される。
- 法定準備金が0円設定の従業員は、予測法定控除合計÷20を使う。
- 設定を無効にした項目は、無効日以降の日報入力項目から除外される。
