## 4. 残高列の扱い

資料の「寮費金額残」「前借り残」「貯金残高」は設定値ではなく、2026年10月31日時点の残高である。
日額・利用有無の設定と同じ更新では残高へ変換しない。残高は二重計上防止のため、開始残高取引として別途監査可能な形で登録する。

資料上の正数は次のとおり。

- 寮費金額残: 10名
- 前借り残: `FUYO-22` の7,000円
- 貯金残高: `FUYO-3` 168,000円、`FUYO-6` 63,000円、`FUYO-7` 2,000円、`FUYO-10` 22,000円、`FUYO-13` 4,000円、`FUYO-16` 28,000円

## 5. 検証条件

- 元の従業員、顧客、日報を削除・更新しない。
- 同じ従業員・同じ項目・同じ適用開始日の再実行で重複履歴を作らない。
- 2026年10月30日以前の日報へ新設定を適用しない。
- 2026年10月31日以降の日報で対象項目だけが表示される。
- 管理手当と寮費日額は資料値を初期値として表示し、日報では手入力変更できる。
