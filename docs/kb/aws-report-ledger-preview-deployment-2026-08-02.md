ProjectAdminSystem V1で作成した帳票、台帳、WebプレビューをAWS DEV環境へ反映し、Cloudflare Access経由で確認できる状態にする。

## 3. 反映した出力機能

### 3.1 PDF／Excel帳票

- 日払い明細
- 月給料明細
- 月次請求書（顧客設定に応じた3パターン）
- 月次労務費一覧（Excelテンプレート出力）
- 作業証明伝票

PDF帳票は「印刷」からJasperReportsのPDFプレビューを開き、プレビュアー上の「印刷」で本印刷する。

月次帳票は締め処理時に生成・保存したファイルを締めVersion単位で取得する。請求書など複数ファイルがある場合は対象一覧から選択して開く。

### 3.2 Webプレビュー

- 日別労務費一覧
- 給与支払表
- 日払い明細の簡易データ確認
- 月給料明細の簡易データ確認
- 月次請求書の簡易データ確認
- 月次労務費一覧の簡易データ確認
- 作業証明伝票の簡易データ確認

HTML印刷対象はThymeleafテンプレートで描画し、ブラウザ標準印刷を利用する。履歴保存は行わない。

### 3.3 Spreadsheet台帳

- 月間集計表
- 月間労務表
- 労務費支払一覧
- 入金確認表
- 従業員別台帳確認

台帳テンプレートおよび生成結果はS3書類管理領域で管理する。

## 6. 画面確認手順

1. `https://project-admin.fuyo-system.com/` を開く。
2. Cloudflare Accessへ許可済みメールアドレスでログインする。
3. ProjectAdminへログインする。
4. `締め処理 → 日次` の帳票タブで日次プレビューと印刷を確認する。
5. `締め処理 → 月次` の帳票タブで簡易プレビューを確認する。
6. 月次帳票の本印刷は対象月を締めた後、「印刷」から保存済みファイルを開く。
7. `締め処理 → 台帳` で対象月、対象者または対象単位を選び、Spreadsheetを開く。
8. `システム運用 → 台帳管理` で台帳マスターとテンプレート編集を確認する。
9. `管理 → 書類管理` で自由書類、生成帳票、バックアップ、テンプレート領域を確認する。

## 7. 注意事項

- 現在のAWSリソース名はDEVである。公開URLから利用できる検証環境であり、本番専用アカウント／prod環境への昇格は別作業とする。
- 月次の保存済み帳票は締め処理を実行したVersionに対して生成される。今回追加した帳票を既に締め済みの月で確認する場合は、再締めを実行する。
- 実データが存在しない対象月では、プレビューが0件または帳票生成対象なしになる場合がある。
