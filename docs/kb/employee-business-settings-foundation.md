# 従業員管理・業務設定基盤 V1

## 1. 目的

従業員の在籍状態、退職処理、給与締日、月次締め帳票、寮費の設定元を明確にし、画面から安全に管理できるようにする。

## 2. 管理画面

管理者メニューの「業務設定」から次のタブを使用する。

| タブ | 管理内容 |
| --- | --- |
| 退職時文言・TODO | 退職ダイアログのタイトル、案内文、警告見出し、必須／任意TODO |
| 締日設定 | 給与締日と給与支払日 |
| 締め帳票 | 月次締め時に生成する帳票、実行順、バックアップ保存年数 |
| 寮費設定 | 一人部屋・複数人部屋の日額と有効状態 |

業務設定画面とAPIは `SYS_ADMIN` のみ使用できる。

## 3. 従業員の状態遷移

### 3.1 新規登録

- 在籍状態は `ACTIVE` で作成する。
- 退職日は未設定とする。
- `activeFlag` は `true` とする。

### 3.2 通常編集

- 社員コードは作成後に変更できない。
- 在籍状態は `ACTIVE` または `LEAVE` のみ選択できる。
- 退職日と `activeFlag` は画面から直接編集しない。
- 退職済み従業員は通常編集できない。

### 3.3 退職

- 専用の退職処理から実行する。
- 管理者が設定した必須TODOをすべて確認する。
- 退職日は入社日以降とする。
- 完了時に次の値を同時に更新する。
  - `employmentStatus = RESIGNED`
  - `resignDate = 指定された退職日`
  - `activeFlag = false`

### 3.4 退職取消

- 退職済み従業員に対して専用操作を使用する。
- 完了時に `ACTIVE` へ戻し、退職日を消去し、`activeFlag = true` とする。

### 3.5 削除

次の業務データから参照されている場合は削除せず、退職処理を使用する。

- 日報
- 翌日準備
- 貸付
- 積立
- 旧勤怠
- 住民税

参照のない誤登録のみ論理削除できる。

## 4. 退職時文言・TODO

### 4.1 文言

テナントごとに次の3項目を管理する。

- ダイアログタイトル
- 案内文
- 警告見出し

未登録の場合はアプリケーションの既定文言を表示する。

### 4.2 TODO

各TODOは次の項目を持つ。

| 項目 | 内容 |
| --- | --- |
| code | 一意の業務コード。作成後は変更不可 |
| name | 退職画面へ表示する項目名 |
| description | 管理者・担当者向けの説明 |
| requiredFlag | 未確認時に退職を禁止するか |
| displayOrder | 表示順 |
| activeFlag | 退職画面へ表示するか |

## 5. 締日設定

V1では設定コード `PAYROLL` を使用する。

- 給与締日：月内の日付または月末
- 給与支払日：対象月からの月オフセットと日付または月末

保存値は月次締め期間の計算と、月次請求から顧客取引へ設定する支払予定日の計算に使用する。

## 6. 締め帳票

### 6.1 責務

「システム運用 → 帳票管理」は帳票レイアウト、ジョブ、出力形式を管理する。

「管理者メニュー → 業務設定 → 締め帳票」は、登録済み月次帳票について次だけを管理する。

- 月次締めで生成するか
- 実行順
- バックアップ保存年数

同じ帳票定義を二重に作成しない。

### 6.2 月次締めとの接続

`monthly_closing_output_definition` に `REPORT` 設定が存在する場合、月次締めは有効な設定だけを実行順に生成する。

設定がまだ1件もない既存環境では、互換性のため従来どおり有効な月次帳票をすべて生成する。

締め帳票として有効でも、帳票管理側で無効な場合は月次締めを失敗させる。帳票が1件も有効でない場合も締め済みにしない。

V1では締め帳票はすべて必須として扱う。任意帳票の失敗継続と、台帳の自動確定は後続整備で対応する。

## 7. API

### 従業員画面

| Method | Path | 用途 |
| --- | --- | --- |
| GET | `/api/employees/resignation-configuration` | 退職文言と有効TODO取得 |
| POST | `/api/employees/{id}/resign` | 退職処理 |
| POST | `/api/employees/{id}/cancel-resignation` | 退職取消 |

### 管理者業務設定

基底パス：`/api/admin/business-settings`

| Method | Path | 用途 |
| --- | --- | --- |
| GET/PUT | `/resignation-message` | 退職文言取得・保存 |
| GET/POST | `/resignation-checklist` | TODO一覧・作成 |
| PUT/DELETE | `/resignation-checklist/{id}` | TODO更新・削除 |
| GET/PUT | `/closing-setting` | 給与締日・支払日取得・保存 |
| GET/PUT | `/closing-outputs` | 月次締め帳票取得・一括保存 |
| GET/PUT | `/dormitory-fees` | 寮タイプ別日額取得・一括保存 |

## 8. DB適用

追加DDL：

`backend/src/main/resources/sql/employee/business_settings_v1.sql`

実行内容：

- `employee_resignation_setting` 作成
- 退職TODOコードの一意制約追加
- 既存月次帳票から締め帳票初期設定を作成

AWS環境ではランタイムスキーマ更新スクリプトに含まれる。

## 9. V1以降の候補

- 契約情報の適用開始日・終了日による履歴化
- 退職時に確認したTODOと実行者の監査履歴保存
- 任意締め帳票が失敗した場合の継続条件
- 台帳の月次締め自動確定
- 旧 `employee_timesheet` の廃止と日報への統一
