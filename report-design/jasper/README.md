# Jasper帳票 レイアウト編集ワークスペース

このディレクトリは、実行中の帳票へ影響を与えずに `.jrxml` のレイアウトを調整するための作業場所です。
アプリケーションが実際に読むテンプレートは `backend/src/main/resources/reports` にあり、ここにあるファイルは自動では反映されません。

## ディレクトリ

- `baseline-2026-09-13`: 2026年9月13日時点の実行用テンプレートの退避コピー。比較・復旧用なので編集しません。
- `working`: 利用者・AIが編集するコピー。まずはこちらだけを変更します。
- `backend/src/main/resources/reports`: 動作確認・本番ビルドに使う実行用テンプレート。このワークスペースの外にあります。

## 編集から反映まで

1. `working` 内の対象 `.jrxml` をJaspersoft Studio等で編集します。
2. `baseline-2026-09-13` と比較し、意図しない項目名・パラメータ名・データ型の変更がないことを確認します。
3. JRXMLをコンパイルし、構文と式にエラーがないことを確認します。
4. レビュー済みのファイルだけを、同名の `backend/src/main/resources/reports` へコピーします。
5. 対象帳票のテストとLocalプレビューを実行し、PDFの改ページ・文字切れ・データ差し込みを確認します。
6. 問題がなければ実行用テンプレートと `working` を一緒にコミットします。

## AIへ修正を依頼するときの制約

- 原則として、位置・幅・高さ・フォント・罫線・余白・改ページだけを変更します。
- `$F{...}`、`$P{...}`、`$V{...}` の名前とJava型は、バックエンド契約も同時に変更する場合を除いて変えません。
- SQLクエリをJRXMLへ追加しません。このシステムはサーバー側で準備したデータを帳票へ渡します。
- サブレポート、画像、フォントを追加する場合は、参照先がLocalとAWSの両方で利用できることを確認します。
- `baseline-2026-09-13` は編集せず、復旧可能な原本として保持します。

## 差し戻し

レイアウト調整で問題が出た場合は、対象ファイルを `baseline-2026-09-13` と比較し、必要なファイルだけ実行用テンプレートへ戻します。他の帳票まで一括で戻さないようにします。
